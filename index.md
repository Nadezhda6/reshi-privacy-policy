# Политика конфиденциальности приложения «РЕШИ»

**Дата последнего обновления: 22 октября 2026 года**

## 1. Общие положения

Приложение «РЕШИ» предназначено для проверки математических выражений. Настоящая политика описывает порядок обработки информации при использовании приложения.

## 2. Сбор и обработка данных

Приложение «РЕШИ» не собирает, не хранит и не передаёт разработчику персональные данные пользователей.

В приложении нет рекламы и аналитики. Вводимые математические выражения обрабатываются непосредственно на устройстве пользователя.

## 3. Передача данных третьим лицам

Приложение не передаёт пользовательские данные третьим лицам.

## 4. Безопасность и хранение данных

Поскольку приложение не собирает и не отправляет разработчику персональные данные, отдельное хранение таких данных разработчиком не осуществляется.

## 5. Изменения политики

В случае изменения функций приложения или порядка обработки данных настоящая политика может быть обновлена. Актуальная версия будет опубликована на этой странице.
